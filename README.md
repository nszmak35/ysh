# 📖 About

**Y Shell (ysh)** is a lightweight Unix shell written in **C** using **GNU Readline**.

## ✨ Features

- 🚀 Fast and lightweight
- ⌨️ GNU Readline support
- 🧩 Built-in commands
- 📜 Command history
- 🎨 Color customization
- 🔧 Keyboard bindings
- 🌍 Alias support

# 📦 Building from Source

## Dependencies

### Arch Linux

```bash
sudo pacman -S base-devel readline
```

### Void Linux

```bash
sudo xbps-install -S base-devel readline-devel
```

### Debian / Ubuntu

```bash
sudo apt install build-essential libreadline-dev
```

### Fedora

```bash
sudo dnf install gcc make readline-devel
```

## Build

```bash
git clone https://github.com/nszmak35/ysh.git
cd ysh
make
sudo make install
```
